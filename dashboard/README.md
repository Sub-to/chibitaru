# 🖥 ちびたるダッシュボード

このPC用の「1画面で全部見える」ダッシュボード。
**お金は一切かかりません**（APIキー不要・無料の公開データだけを使用）。

```
┌──────────────────────────────────────────────────────┐
│ 🚨 紛争アラート ／ 地震アラート（震度3以上）  ← 赤い帯 │
├──────────────────────────────────────────────────────┤
│ 年月日・時刻 │ 宮崎市の天気・週間予報 │ 更新・記録状況 │
├───────────────────────┬──────────────────────────────┤
│ 💡 テック・AI・ガジェット │ 🇯🇵 日本のニュース ／ 🏞 宮崎県 │
│   [AI][テック]         ├──────────────────────────────┤
│   [ガジェット][PC]      │ 🌐 世界のニュース             │
│ 💱 ドル・円・ユーロ      │                              │
└───────────────────────┴──────────────────────────────┘
```

---

## 🚀 使い方

### Ubuntu / Linux
```bash
bash dashboard/start_dashboard.sh
```

### macOS
```bash
bash dashboard/start_dashboard.sh
```

### Windows
`dashboard\start_dashboard.bat` をダブルクリック

ブラウザが自動で開きます（`http://127.0.0.1:8787/`）。
`start.sh` / `start.bat` のメニュー **5番** からも起動できます。

> 全画面（F11 か画面上で **F** キー）にすると、置きっぱなしで使えます。

## 🖥 情報表示専用機として使う（延命モード）

古いノートPCやタブレットを「常時表示のダッシュボード端末」にする使い方。
**Surface Pro 3 + Ubuntu** で動作を確認しています。

### 枠なし全画面で起動
```bash
bash dashboard/kiosk.sh              # キオスク（完全全画面）
bash dashboard/kiosk.sh --window     # 枠付きウィンドウ
```
サーバーとブラウザをまとめて面倒みます。閉じるとサーバーも止まります。
Chromium系があればアプリモード、無ければ Firefox、それも無ければ既定のブラウザを使います。
Wayland も自動で見分けます。

### アプリ一覧・自動起動に登録（GNOME）
```bash
bash dashboard/linux/install-desktop.sh              # アプリ一覧に追加
bash dashboard/linux/install-desktop.sh --autostart  # ログイン時に自動で開く
bash dashboard/linux/install-desktop.sh --remove     # 取り消し
```

### 画面を消さない設定
```bash
gsettings set org.gnome.desktop.session idle-delay 0
gsettings set org.gnome.settings-daemon.plugins.power sleep-inactive-ac-type 'nothing'
```

### 非力なPCでの自動調整

起動時にメモリとCPUを見て、**メモリ4.5GB未満**・**Atom/Celeron系**・**2コア以下**の
いずれかなら自動で **軽量モード** に入ります。

| | 通常 | 軽量 |
|---|---|---|
| 点滅アニメーション | あり | なし（再描画が重いため） |
| 1タブの記事数 | 40件 | 20件 |
| ニュース更新 | 15分 | 30分 |
| 同時接続数 | 8 | 3 |

手動で切り替えるなら `config.json` の `"performance"` を `"light"` / `"normal"` に。
一時的に試すだけなら環境変数でも指定できます。

```bash
CHIBITARU_DASH_PERF=light bash dashboard/start_dashboard.sh
```

> Surface Pro 3（Core i5 / 8GB）は**通常モード**と判定されます。軽量化は不要なので、
> そのままで問題ありません。

### 電池の持ち

画面が隠れている間（ロック・最小化）は自動で取得を止めます。
復帰したときに最新へ追いつくので、放置していても情報が古いままにはなりません。

## 📐 文字が小さい / 大きいとき

画面上で **`+`** と **`-`** キーで変えられます。設定はこの端末に記憶されます。

高精細画面（Surface Pro 3 の 2160×1440 など）では、OS側の拡大率を見て
二重拡大にならないよう自動調整しています。それでも好みに合わなければ上のキーでどうぞ。

`config.json` で固定することもできます。

```jsonc
{ "ui": { "scale": 1.15 } }   // "auto" または 0.85〜1.6
```

縦の狭い画面（3:2 の Surface など）では、高さに応じて週間予報などを
自動で隠して1画面を死守します。

## 💰 なぜ無料なのか

| 内容 | 情報源 | 料金 |
|------|--------|------|
| 天気・週間予報 | 気象庁 公開JSON | 無料・キー不要 |
| 現在の気温・湿度 | Open-Meteo | 無料・キー不要 |
| 地震（震度3以上） | 気象庁 震度リスト | 無料・キー不要 |
| 海外の地震（M6.0以上） | USGS | 無料・キー不要 |
| 紛争アラート | 国連ニュース・GDACS・各国報道RSS | 無料 |
| ニュース各種 | 各媒体の公開RSS／Googleニュース検索RSS | 無料 |
| 為替 | open.er-api.com（予備: frankfurter） | 無料・キー不要 |

さらに通信を減らす工夫：

- **条件付きGET**（ETag / Last-Modified）── 更新が無ければ本文を再ダウンロードしない
- **ディスクキャッシュ** ── 種類ごとに更新間隔を分けている（地震3分／ニュース15分／天気30分）
- **取得はサーバー側で1回だけ** ── 画面を何枚開いても通信量は増えない
- **pip install 不要** ── Python標準ライブラリだけで動く

## 🚨 アラートについて

**地震**：気象庁の震度リストから **最大震度3以上** を拾います（`min_shindo` で変更可）。
海外は USGS の **M6.0以上**。赤帯の右端に直近の震度を大きく出します。

**紛争**：国連・GDACS・各国報道のRSSを、キーワード（紛争／空爆／ミサイル／ceasefire など）で
採点して拾い上げます。ゲームや映画の見出しは減点して弾いています。日本関連（領空侵犯・
弾道ミサイルなど）も対象です。

> ⚠️ これは**報道の要約であって、公式の避難情報ではありません**。
> 実際に身の安全に関わる場面では、必ず気象庁・自治体・NHK の情報を直接確認してください。

赤帯の右端 `▾` （または **A** キー）で全アラートの一覧が開きます。

### デスクトップ通知

画面を見ていなくても気づけるよう、**震度4以上**でOSの通知を出します
（画面には震度3以上を表示）。同じ地震は一度だけ。うるさければ切れます。

```jsonc
{ "notify": { "enabled": false } }        // 通知しない
{ "notify": { "min_shindo": 5 } }         // 震度5弱以上だけ
```

## 📓 Obsidian への記録

見たニュースは自動でVaultに残ります。

```
<Vault>/Dashboard/
├── Daily/2026-08-24.md      ← その日の記録（日付・見出し・ソース元・リンク）
├── Sources/NHK.md           ← ソース元ノート
└── Topics/AI.md             ← トピックノート
```

日付ノートの中身：

```markdown
## 🏞 宮崎県のニュース

### 07:00 宮崎市の中心市街地に新しい複合施設がオープン
- 🏷 ソース元: [[宮崎日日新聞]] ／ トピック: [[宮崎県]] [[地域]]
- 🔗 [記事を開く](https://...)
```

`[[ウィキリンク]]` で **日付 ⇄ ソース元 ⇄ トピック** が繋がるので、
**グラフビュー**で「この日 → この媒体 → このテーマ」と辿れます。
同じ記事は二度書きません（既読URLを覚えています）。

### Vaultの場所を教える

**すでにObsidianを使っている場合**は、新しく作らずその場所を指定します。
どこにあるか分からなければ、`.obsidian` フォルダを探すと見つかります。

```bash
find ~ -maxdepth 4 -name ".obsidian" -type d 2>/dev/null
```

**まだ無い場合**は、フォルダごと用意できます（既にあれば中身は触りません）。

```bash
python3 dashboard/server.py --init-vault
```

場所の指定は次の順に見ます。

| 優先 | 方法 | 自動起動でも効くか |
|---|---|---|
| 1 | 環境変数 `CHIBITARU_VAULT` | ❌ 効かないことがある |
| 2 | `config.json` の `"vault"` | ✅ 確実 |
| 3 | 既定 `~/ObsidianVault` | ✅ |

```jsonc
// dashboard/config.json
{ "vault": "~/Documents/MyVault" }
```

> ⚠️ 自動起動（`.desktop`）から立ち上げると `~/.bashrc` が読まれないため、
> 環境変数だけだとVaultを見失います。**常時表示で使うなら `config.json` に書いてください。**

環境変数で一時的に指定するなら:

```bash
export CHIBITARU_VAULT="$HOME/Documents/MyVault"     # Linux / macOS
setx CHIBITARU_VAULT "C:\Users\you\MyVault"        # Windows(PowerShell)
```

記録したくないときは `--no-vault` を付けてください。

## 🛠 困ったとき

### まず情報源チェック
```bash
python3 dashboard/server.py --check
```
どのRSS／APIが生きているか一覧で出ます。
数本 ❌ でも他が埋めるので画面は動きます。直したいときは
`dashboard/sources.py` のURLを差し替えてください。

### ニュースが出ない
- ネット接続と、上の `--check` の結果を確認
- 会社や学校のネットだと一部のRSSが塞がれていることがあります

### 1画面に収まらない
画面上で **`-`** キーを押して文字を小さくしてください（設定は記憶されます）。
横1180px未満・縦700px未満では、週間予報などを自動で隠して1画面を守ります。

### 文字が小さすぎて読めない（高精細画面）
**`+`** キーで大きくできます。Ubuntu 側の拡大率は
「設定 → ディスプレイ → 拡大/縮小」で変えられます（Surface Pro 3 なら 200% が既定）。

## ⌨️ ショートカット

| キー | 動作 |
|------|------|
| `1`〜`4` | 左パネルのタブ切替（AI／テック／ガジェット／PC） |
| `←` `→` | 左パネルのタブを順に切替 |
| `R` | いま取り直す |
| `A` | アラート一覧の開閉 |
| `F` | 全画面 |
| `+` `-` | 文字サイズの拡大・縮小 |

## ⚙️ 設定を変える

`dashboard/config.example.json` を `dashboard/config.json` にコピーして、
変えたい項目だけ書きます。

```jsonc
{
  "alerts": { "min_shindo": 4 },        // 震度4以上だけにする
  "intervals": { "news": 1800 },        // ニュースの更新を30分に
  "location": { "name": "延岡市", "lat": 32.5822, "lon": 131.6653 }
}
```

他の市町村にしたいときは `lat` / `lon` と、気象庁の
`jma_area`（県）・`jma_class10`（細分区域）を変えてください。

### 毎朝1回だけ記録したい（画面は開かない）
```bash
python3 dashboard/server.py --once
```
cron や タスクスケジューラ に登録すると、Vaultにその日のニュースが溜まります。

## 🔒 プライバシー

- サーバーは `127.0.0.1`（このPCの中）でだけ待ち受けます。外からは繋がりません
- 個人情報はどこにも送信しません。各RSS／APIを読みに行くだけです
- 集めたデータはこのPCの中（キャッシュとVault）にしか残りません

キャッシュの場所: `~/.chibitaru/dashboard/`
