# 🖥 ちびたるダッシュボード

このPC用の「1画面で全部見える」ダッシュボード。
**お金は一切かかりません**（APIキー不要・無料の公開データだけを使用）。

```
┌──────────────────────────────────────────────────────┐
│ 🚨 紛争アラート ／ 地震アラート（震度3以上）  ← 赤い帯 │
├──────────────────────────────────────────────────────┤
│ 年月日・時刻 │ 宮崎市の天気・週間予報 │ 更新・記録状況 │
├───────────────────────┬──────────────────────────────┤
│ 💡 テック・AI・ガジェット │ 🇯🇵 日本のニュース ／ 🏞 宮崎県 │
│   [AI][テック]         ├──────────────────────────────┤
│   [ガジェット][PC]      │ 🌐 世界のニュース             │
│ 💱 ドル・円・ユーロ      │                              │
└───────────────────────┴──────────────────────────────┘
```

---

## 🚀 使い方

### macOS / Linux
```bash
bash dashboard/start_dashboard.sh
```

### Windows 11
`dashboard\start_dashboard.bat` をダブルクリック

ブラウザが自動で開きます（`http://127.0.0.1:8787/`）。
`start.sh` / `start.bat` のメニュー **5番** からも起動できます。

> 全画面（F11 か画面上で **F** キー）にすると、サブモニタに置きっぱなしで使えます。

## 💰 なぜ無料なのか

| 内容 | 情報源 | 料金 |
|------|--------|------|
| 天気・週間予報 | 気象庁 公開JSON | 無料・キー不要 |
| 現在の気温・湿度 | Open-Meteo | 無料・キー不要 |
| 地震（震度3以上） | 気象庁 震度リスト | 無料・キー不要 |
| 海外の地震（M6.0以上） | USGS | 無料・キー不要 |
| 紛争アラート | 国連ニュース・GDACS・各国報道RSS | 無料 |
| ニュース各種 | 各媒体の公開RSS／Googleニュース検索RSS | 無料 |
| 為替 | open.er-api.com（予備: frankfurter） | 無料・キー不要 |

さらに通信を減らす工夫：

- **条件付きGET**（ETag / Last-Modified）── 更新が無ければ本文を再ダウンロードしない
- **ディスクキャッシュ** ── 種類ごとに更新間隔を分けている（地震3分／ニュース15分／天気30分）
- **取得はサーバー側で1回だけ** ── 画面を何枚開いても通信量は増えない
- **pip install 不要** ── Python標準ライブラリだけで動く

## 🚨 アラートについて

**地震**：気象庁の震度リストから **最大震度3以上** を拾います（`min_shindo` で変更可）。
海外は USGS の **M6.0以上**。赤帯の右端に直近の震度を大きく出します。

**紛争**：国連・GDACS・各国報道のRSSを、キーワード（紛争／空爆／ミサイル／ceasefire など）で
採点して拾い上げます。ゲームや映画の見出しは減点して弾いています。日本関連（領空侵犯・
弾道ミサイルなど）も対象です。

> ⚠️ これは**報道の要約であって、公式の避難情報ではありません**。
> 実際に身の安全に関わる場面では、必ず気象庁・自治体・NHK の情報を直接確認してください。

赤帯の右端 `▾` （または **A** キー）で全アラートの一覧が開きます。

## 📓 Obsidian への記録

見たニュースは自動でVaultに残ります。

```
<Vault>/Dashboard/
├── Daily/2026-08-24.md      ← その日の記録（日付・見出し・ソース元・リンク）
├── Sources/NHK.md           ← ソース元ノート
└── Topics/AI.md             ← トピックノート
```

日付ノートの中身：

```markdown
## 🏞 宮崎県のニュース

### 07:00 宮崎市の中心市街地に新しい複合施設がオープン
- 🏷 ソース元: [[宮崎日日新聞]] ／ トピック: [[宮崎県]] [[地域]]
- 🔗 [記事を開く](https://...)
```

`[[ウィキリンク]]` で **日付 ⇄ ソース元 ⇄ トピック** が繋がるので、
**グラフビュー**で「この日 → この媒体 → このテーマ」と辿れます。
同じ記事は二度書きません（既読URLを覚えています）。

### Vaultの場所を教える

他のちびたるツールと同じ環境変数を使います。

```bash
# macOS / Linux
export CHIBITARU_VAULT="/path/to/YourVault"

# Windows（PowerShell、一度だけでOK）
setx CHIBITARU_VAULT "C:\Users\you\Documents\YourVault"
```

未設定なら `~/ObsidianVault` を見に行きます。
記録したくないときは `--no-vault` を付けてください。

## 🛠 困ったとき

### まず情報源チェック
```bash
python3 dashboard/server.py --check
```
どのRSS／APIが生きているか一覧で出ます。
数本 ❌ でも他が埋めるので画面は動きます。直したいときは
`dashboard/sources.py` のURLを差し替えてください。

### ニュースが出ない
- ネット接続と、上の `--check` の結果を確認
- 会社や学校のネットだと一部のRSSが塞がれていることがあります

### 1画面に収まらない
ブラウザの拡大率を 90% / 80% に下げてください（Ctrl と `-`）。
横1180px未満では週間予報を自動で隠します。

## ⚙️ 設定を変える

`dashboard/config.example.json` を `dashboard/config.json` にコピーして、
変えたい項目だけ書きます。

```jsonc
{
  "alerts": { "min_shindo": 4 },        // 震度4以上だけにする
  "intervals": { "news": 1800 },        // ニュースの更新を30分に
  "location": { "name": "延岡市", "lat": 32.5822, "lon": 131.6653 }
}
```

他の市町村にしたいときは `lat` / `lon` と、気象庁の
`jma_area`（県）・`jma_class10`（細分区域）を変えてください。

### 毎朝1回だけ記録したい（画面は開かない）
```bash
python3 dashboard/server.py --once
```
cron や タスクスケジューラ に登録すると、Vaultにその日のニュースが溜まります。

## 🔒 プライバシー

- サーバーは `127.0.0.1`（このPCの中）でだけ待ち受けます。外からは繋がりません
- 個人情報はどこにも送信しません。各RSS／APIを読みに行くだけです
- 集めたデータはこのPCの中（キャッシュとVault）にしか残りません

キャッシュの場所: `~/.chibitaru/dashboard/`
