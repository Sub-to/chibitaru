# お知らせ枠

画面の一番上を右から左へ流れるあれ。集めるのは `chibitaru-news`、
流すのは `NewsTicker`（`tui/panels.py`）。

## 出るもの

| | 情報源 | 条件 |
|---|---|---|
| 地震 | 気象庁 `quake/data/list.json` | **震度3以上**・24時間以内・最大3件 |
| 注意報 | 気象庁 `warning/data/warning/{府県}.json` | 発表中・継続中のもの |
| 天気と気温 | 気象庁 `forecast/data/forecast/{府県}.json` | 予報文と最低〜最高 |
| 紛争 | NHK 国際ニュース RSS | 争いに関わる語を含むもの・最大4件 |

急ぐものが先に来る。地震 → 注意報 → 天気 → 紛争。

## 地域

```
chibitaru-news --地域 宮崎県
chibitaru-news --地域一覧
```

府県予報区は 58 区分（北海道は 7 つに分かれ、鹿児島は奄美が別）。
一覧は気象庁の `bosai/common/const/area.json` から起こした。
手で書き写すと必ずどこかを間違える。

**府県の中の、先頭の区分を見ている。** 宮崎県なら南部平野部（宮崎市が
入る）。どこを見ているかは表示に出す —— 県名だけ出すと、隣の山沿いの
予報を自分の町のものだと思い込む。

## 注意報の名前

気象庁の JSON は**コードしか返さない**（`{"code":"14","status":"発表"}`）。
対応表は公開されていない。

そこで、実際に流れている防災 XML（VPWW5x）から起こした。あれには
`<Name>雷注意報</Name><Code>14</Code>` の形で両方入っている。

```
chibitaru-news --学ぶ
```

で、その時に出ているものを覚えて増やす。**冬の注意報は夏には流れて
こないので、この表は最初から完全にはならない。** 知らないコードには
名前を作らず「ほか2件」と数だけ言う。「たぶん大雪注意報」と出して
外すより、種類が分からないと言うほうがいい。

同梱してあるのは実データで確認できた 8 種類だけ（`profiles/warning-codes.json`）。

## 取りに行き方

画面が動いている間、**10分おきに別の腕で取りに行く**。画面の中で
取りに行くと、電波が悪い時に画面ごと固まる。

失敗しても何も言わない。電波が無いのは普通のことで、そのたびに
画面に出してもできることはない。

**情報源ごとに別々に貯める**（`~/.cache/chibitaru/news.d/`）。
テザリングでは片方だけ落ちることがあり、まとめて書き出すと取れな
かったぶんが消える。取れたものだけ入れ替えれば、前のものは残る。

## 踏んだもの

- **同じ地震が二度出た。** 震度速報（震源が空）と、あとから出る
  震源・震度情報の両方が `list.json` に並ぶ。起きた時刻でまとめ、
  中身の多いほうを採る
- **予報文が語の途中で切れた**（「雷を伴」で終わる）。予報文は
  全角空白で区切られているので、詰めてから字数で切らず、区切り
  ごとに足していってはみ出す手前でやめる
- **字数で切ると右が余る。** 日本語は 1 文字 2 桁。英語の見出しが
  来た時に画面の右が空く。桁数で切る（`dw()`）
- **`/etc/chibitaru/news` に「情報源は未接続」と書いたまま**にして
  いた。繋いだ後もそう表示し続けていた。あそこに置くのは、まだ一度も
  取りに行けていない間の文言だけにする
